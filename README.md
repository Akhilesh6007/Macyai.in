# Macy AI — Intelligent Video Creation Studio

Macy AI is an AI-powered multilingual video-generation application that transforms text topics into narrated videos using artificial intelligence, stock footage, automated voiceovers, subtitles, and FFmpeg rendering.

## Tech Stack

- **Frontend:** Streamlit
- **Backend:** FastAPI, Python
- **Generative AI:** Google Gemini API
- **Stock Footage:** Pixabay API
- **Text-to-Speech:** Edge TTS
- **Video Processing:** FFmpeg
- **Task Management:** Background jobs and JSON-based task history

## Key Features

- AI-powered script and keyword generation
- Automated stock-video collection
- English and Hindi voiceover generation
- Automatic subtitles
- Scene planning and timing
- Video rendering and MP4 export
- Task status tracking, preview, and download

## Local Setup

1. Clone the repository.
2. Create a Python virtual environment.
3. Install the project dependencies.
4. Configure the required API credentials using `.env.example`.
5. Run the FastAPI backend.
6. Start the Streamlit frontend.

## Development Status

The core video-generation workflow has been implemented. Additional editing, audio-enhancement, and deployment features are being developed and tested.
